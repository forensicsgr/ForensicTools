# Dumpit v. 20230711
Magnet DumpIt for Windows generates full memory crash dumps that are interoperable with multiple analysis tools and products such as WinDbg, and the Comae Platform.  
To use the tool:

1. DumpIt.exe.  
2. Press “y” to start the acquisition.  
3. When the acquisition is finished, you will have a .dmp file in the same folder.
